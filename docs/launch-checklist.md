## 1. 사업자등록 — 대표

**왜:** 카드 결제를 받으려면 결제사와 계약해야 하고, 계약 심사에 사업자등록증이 들어간다. 국내 결제사는
대개 통신판매업 신고증도 요구한다.

**하는 법**
1. 홈택스(온라인) 또는 관할 세무서에서 사업자등록 신청.
   - 업종(소프트웨어 개발 · 공급 / 온라인 서비스 등)과 과세 유형(간이 · 일반)은 **세무서나 세무사와 정한다.**
     해외 고객에게 달러로 팔 계획이면 그 사실도 같이 말한다(부가세 처리 방식이 달라진다).
2. 통신판매업 신고(정부24 · 시군구청).
   - 신고에 결제사가 발급하는 서류(구매안전서비스 이용 확인 등)가 필요할 수 있다. 그 경우 **8번과 순서가
     얽히니** 신고처에 먼저 물어본다.

**끝났다는 신호:** 사업자등록증(PDF) · 통신판매업 신고증(필요하면).

## 2. API 키 3개 발급 + 사용 한도 — 대표

직원 다섯이 쓰는 회사는 셋이다: **Anthropic**(전략가 · 개발자), **Google Gemini**(분석가 · 디자이너),
**OpenAI**(작가).

**공통 원칙**
- 각 콘솔에서 **결제수단 등록 → 키 발급 → 월 사용 한도(또는 예산 알림)** 순서. 한도가 먼저다 — 키가 새거나
  버그로 무한 호출이 나도 손해가 그 안에서 멈춘다. 처음에는 회사마다 **월 $20~50** 정도로 낮게.
- 키 이름은 `ai-company-prod` 처럼 용도가 보이게.
- **키를 채팅 · 메일 · 메신저에 붙여넣지 않는다.** 3번에서 대표가 직접 서버에 넣는다.

**회사별**
| 회사 | 어디서 | 메모 |
|---|---|---|
| Anthropic | Claude 플랫폼 콘솔(platform.claude.com) → API Keys · Billing | 크레딧 선결제 방식. 사용 한도를 Limits 에서 건다 |
| Google Gemini | Google AI Studio(aistudio.google.com) → API key | 결제는 연결된 Google Cloud 프로젝트에서. **예산 알림**을 Cloud 결제 화면에서 건다 |
| OpenAI | OpenAI 플랫폼(platform.openai.com) → API keys · Billing | Usage limits 에서 월 한도 |

**끝났다는 신호:** 키 3개가 각 콘솔에 있고, 한도가 걸려 있다.

## 3. 키를 서버에 넣기 — 대표(키 입력) + Claude(연결)

서버(Cloud Run)는 키를 **환경변수**로 받는다: `ANTHROPIC_API_KEY` · `GEMINI_API_KEY` · `OPENAI_API_KEY`.
값은 Google **Secret Manager** 에 두고 서비스는 이름으로만 가리킨다 — 키가 배포 설정 화면에 평문으로 남지 않는다.

**대표가 할 것 — 키 입력 (터미널, 화면에 키가 찍히지 않는다)**
```bash
read -s KEY && printf '%s' "$KEY" | gcloud secrets create anthropic-key --data-file=- --project ai-company-1c4da && unset KEY
```
같은 줄을 `gemini-key` · `openai-key` 이름으로 두 번 더. (붙여넣고 Enter. 아무것도 안 보이는 게 정상이다.)

**Claude 에게 넘길 것 — 연결 (키 값은 다루지 않는다)**
- 서비스 계정에 세 비밀의 읽기 권한 주기
- `gcloud run services update ai-company --update-secrets ...` 로 세 환경변수 연결
  (`update` 는 **다른 설정을 지우지 않는다** — `deploy.sh deploy` 는 환경변수를 통째로 덮어쓰니 쓰지 않는다)
- `PROVIDER_MODE=real` 로 바꾸기 — 키가 빠지면 **조용히 Mock 으로 떨어지지 않고 실패**하게
- 프리플라이트(`/api/preflight`)로 확인

**끝났다는 신호:** 화면의 MOCK 배지가 사라지고, 프리플라이트가 세 회사 모두 "키 있음".

## 4. 실제 첫 실행 · 원가 측정 → 가격 확정 — Claude(실행) + 대표(결정)

**왜:** 지금 요금제(스타터 $29 · 프로 $49 · 비즈니스 $79)의 크레딧 수는 **추정** 위에 서 있다. 프로젝트 1건의
실제 원가를 한 번도 재지 않았다. 결제를 붙이기 전에 숫자를 확정해야 한다 — 붙인 뒤에 바꾸면 이미 낸 고객이 있다.

**순서 (STATUS.md "키를 받으면"과 같다)**
1. 프리플라이트 — 호출 없음, 무료
2. `scripts/first_real_run.py` — 회사마다 최소 호출 1번
3. 제공자 시험(보류돼 있던 15개가 자동으로 걸린다) + 실제 계약 시험(몇 센트)
4. `scripts/first_real_run.py --company` — 실제 직원으로 프로젝트 하나 완주
5. `scripts/measure_costs.py --runs 10` — 10건을 돌려 **건당 원가 중앙값 · p90**

**비용:** 추정 $6~60(호출 20~40회 × $0.03~0.15 × 10건). 실측 전이라 폭이 넓다. 2번의 한도 안에서 돈다.
**대표가 승인해야 시작한다** — 돈이 나가는 첫 단계다.

**대표가 할 것:** 측정 결과(원가 비율이 상한 35% 안인가 · 요금제마다 월 몇 건인가)를 보고 가격 · 크레딧을 정한다.
Claude 가 `pricing.json` 을 고치고 화면의 "추정" 문구를 "실측"으로 바꾼다.

## 5. 도메인 구입 · 연결 — 대표 + Claude

**먼저 읽을 것:** [deploy.md](deploy.md) — "도메인 사기 전에 읽을 것".

1. **대표:** 도메인 구입(가비아 · Cloudflare · Namecheap 등).
2. **Claude:** Firebase Hosting 에 사용자 도메인 추가 → 넣어야 할 DNS 레코드를 정리해 드린다.
3. **대표:** 도메인 회사 화면에서 그 레코드를 넣는다. 전파에 몇 분 ~ 하루.
4. **Claude:** `PUBLIC_URL` 을 새 주소로(메일 속 링크가 이 주소를 쓴다), HTTPS 확인.

**끝났다는 신호:** 새 주소로 열리고 자물쇠(HTTPS)가 뜬다.

## 6. 이메일 발송(SMTP) — 대표(계정) + Claude(연결)

**왜:** 비밀번호 재설정 · 이메일 확인은 **이미 만들어져 있고 발송만 꺼져 있다.** 지금은 메일이 서버 로그에만 남는다.

1. **대표:** 발송 서비스 계정(Amazon SES · Resend · Postmark 등). **5번의 도메인으로** 보내야 스팸함에 덜 간다 —
   서비스가 안내하는 SPF · DKIM 레코드를 도메인에 넣는다.
2. **대표:** SMTP 접속 정보(주소 · 계정 · 비밀번호)를 3번처럼 Secret Manager 에 `smtp-url` 로 넣는다.
   형식: `smtps://계정:비밀번호@호스트:465`
3. **Claude:** `SMTP_URL` · `MAIL_FROM`(예: `no-reply@새도메인`) 연결 → 재설정 메일 한 통 실제 발송 확인.

## 7. 약관 · 개인정보처리방침 · 환불정책 — Claude(초안) + 대표 · 전문가(검토)

**왜:** 결제사 심사에 거의 항상 들어가고, 개인정보처리방침은 회원가입을 받는 서비스라면 공개해야 한다.

- **Claude:** 이 제품의 실제 동작에 맞춘 초안 — 무엇을 저장하나(계정 · 프로젝트 파일 · 첨부 · 고객 API 키는 암호화),
  어디에 저장하나(Google Cloud 서울 리전), 크레딧 · 환불 규칙, AI 산출물의 한계(검수를 거쳐도 틀릴 수 있다).
  화면에 페이지로 붙이고 가입 화면 · 결제 화면에서 링크.
- **대표:** 내용 확인. 가능하면 **법률 전문가 검토** — 초안은 초안이다.

## 8. 결제사(PG) 선택 · 가입 · 심사 — 대표

지금 가격이 **달러**라 먼저 정할 것이 있다: **누구에게 무엇으로 받나.**

| 선택지 | 맞는 경우 | 메모 |
|---|---|---|
| Paddle · Lemon Squeezy (판매 대행 · MoR) | 해외 고객 · 달러 구독 | 판매자 대신 각국 세금(VAT 등)을 처리한다. 한국 사업자 가입 가능 여부 · 수수료를 가입 전에 확인 |
| 토스페이먼츠 · 포트원 | 국내 고객 · 원화 정기결제 | 사업자등록증 · 통신판매업 신고증 · 약관 페이지로 심사. 정기결제(빌링)는 별도 심사일 수 있다 |
| Stripe | — | 한국 사업자를 직접 받지 않는 것으로 알고 있다 — 확인할 것 |

**하는 법:** 가입 → 서류 · 사이트 주소(5번) · 약관(7번) 제출 → 심사 → **테스트 키**(공개 키 · 비밀 키 · 웹훅 서명 키) 발급.

**Claude 에게 넘길 것:** 어느 결제사인지와, 테스트 키를 3번처럼 Secret Manager 에 넣었다는 사실(이름만).

## 9. 카드 결제 연동 — Claude

지금 설정 카드의 "충전" 버튼(데모)을 실제 결제로 바꾼다.

- 요금제 고르기 → 결제사 결제 화면 → 돌아오기
- **웹훅**(결제 완료 · 갱신 · 실패 · 해지 · 환불)으로만 크레딧을 준다 — 화면이 "결제했다"고 말하는 것을 믿지 않는다.
  같은 알림이 두 번 와도 크레딧은 한 번만.
- 해지 · 환불 · 결제 실패 시 다음 갱신 처리, 영수증 링크
- 테스트 키 + 결제사의 **테스트 카드 번호**로 처음부터 끝까지 검증, 화면 시험 추가
- 원가 비율 검사(상한 35%)에 결제 수수료를 넣는다

**끝났다는 신호:** 테스트 모드에서 가입 → 결제 → 크레딧 → 실행 → 해지까지 한 바퀴.
