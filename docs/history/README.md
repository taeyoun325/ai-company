# 이전 제품의 설계 문서

여기 있는 문서들은 **AI COMPANY 가 아니라** 이 저장소에 먼저 있던 제품
("AI 에이전트 컴퍼니" — Claude Code 형 로컬 개발도구)의 설계 기록이다.

지우지 않은 이유: `backend/legacy/` 의 코드가 왜 그렇게 생겼는지 설명하는
유일한 문서이고, 그 코드에서 부품을 꺼내 쓸 예정이기 때문이다.

- `BUILD_PLAN.md` — PM·DEV·QA 3인 체제의 제작 개요. **§9 오케스트레이터
  설계의 직접적인 선행 문헌이다.** "오케스트레이터는 코드다",
  "에이전트 간 대화는 JSON", "검증자는 다른 회사 모델" 세 원칙은
  AI COMPANY 에서도 그대로 유효하다.
- `REDESIGN.md` — 고정 파이프라인을 버리고 대화형 루프로 간 재설계 기록.
  AI COMPANY 는 **다시 고정 파이프라인 쪽으로 돌아온다**(지시서 §9).
  왜 한 번 버렸었는지가 여기 적혀 있다.

현재 제품의 상태는 저장소 루트의 [STATUS.md](../../STATUS.md).
