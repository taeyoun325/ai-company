# 재설계 — Claude Code의 틀 위에 에이전트를 얹는다

## 무엇이 바뀌나

| | 이전 | 새 설계 |
|---|---|---|
| 작업 대상 | 격리된 `projects/<slug>/` | **네 실제 프로젝트 폴더** |
| 진행 방식 | 고정 파이프라인 (PLAN→TEST→REVIEW) | **대화형 에이전트 루프** — 모델이 다음 행동을 정한다 |
| 입력 | 요구사항 한 번 | **여러 턴 대화**. "이제 테스트도 추가해줘"가 이어진다 |
| 에이전트 | 항상 3명이 정해진 순서로 | **메인 1명 + 필요할 때 호출** |
| 안전장치 | 역할별 쓰기 권한(신뢰 경계) | **쓰기·명령 실행 전 승인** |
| 완성도 | 인수기준 충족률 | 없음 (고정 인수기준이 없으므로) |

## 왜 안전장치를 갈아끼우나

신뢰 경계("구현자는 테스트를 못 고친다")는 격리 폴더 + 고정 파이프라인이 있어야
성립했다. 실제 폴더에서 대화형으로 돌면 그 전제가 사라진다.

대신 **위험의 성격도 바뀐다.** 이전에는 "검증이 무의미해지는" 위험이었고,
이제는 "네 진짜 파일이 망가지는" 위험이다. 그래서 방어도 바뀐다:

- **파일 쓰기·수정 전 승인** — 무엇을 어떻게 바꿀지 diff로 보여주고 묻는다
- **명령 실행 전 승인** — `rm`, `git push` 같은 건 항상 묻는다
- **작업 폴더 밖 접근 차단** — `Path.resolve()` 후 루트 비교
- **git 이 있으면 변경 전 상태를 기록** — 되돌릴 수 있게

## 구조

```
사용자 ──▶ 메인 에이전트 (Claude, 대화형 루프)
              │
              ├─ 도구: read / write / edit / list / glob / grep / bash / todo
              │        (write·edit·bash 는 승인 게이트를 통과해야 실행)
              │
              └─ call_agent(role, task)  ← 여기가 "에이전트가 추가된" 지점
                    ├─ planner   : Claude — 큰 작업을 쪼갠다
                    ├─ reviewer  : Gemini — 다른 회사 모델로 교차검토
                    └─ tester    : Claude — 테스트를 짜고 돌린다
```

메인 에이전트는 Claude Code처럼 혼자 다 할 수 있다.
**필요하다고 판단할 때만** 다른 에이전트를 부른다. 그래서 "틀은 그대로인데
에이전트가 추가된" 느낌이 된다.

교차검토를 Gemini로 두는 이유는 이전 설계에서 그대로 살아남는다:
같은 모델끼리 검토하면 같은 실수를 함께 놓친다. 다만 이제 **자동이 아니라
메인 에이전트의 판단** 또는 사용자의 요청으로 호출된다.

## 파일 구성

### 새로 만드는 것
| 파일 | 역할 |
|---|---|
| `workspace.py` | 작업 폴더 지정과 경로 안전 검사 |
| `agent_core.py` | 대화형 에이전트 루프. Tool Runner + 도구 정의 |
| `subagents.py` | planner / reviewer / tester 정의와 호출 |
| `session.py` | 대화 세션 저장·복원 |

### 그대로 쓰는 것
`secrets_broker.py` · `approvals.py`(용도 확장) · `attachments.py` ·
`screen.py` · `usage.py` · `bus.py` · `scheduler.py` · `timeline.py`

### 물러나는 것
`orchestrator.py`(상태머신) · `tools/fs.py`(역할별 권한) ·
`agents/pm.py`·`dev.py`·`qa.py` · `schemas.py`의 Plan/TestSuite
→ `legacy/` 로 옮겨 참고용으로 남긴다. 지우지 않는 이유: 신뢰 경계 실험의
기록이고, 격리 모드로 되돌릴 여지를 남겨두기 위해서.

## UI

홀로그래픽 정체성은 유지하되 **덜 요란하게, 더 고급스럽게** 다듬는다.

- 가운데: Claude Code처럼 **대화 기록**. 도구 호출이 접히는 카드로 흐른다
- 승인이 필요하면 그 자리에서 **diff와 함께** 묻는다
- 왼쪽: 작업 폴더, 에이전트(메인 + 호출된 것들), 토큰·비용
- 오른쪽: 파일 트리, 변경된 파일, 세션 목록
- 스캔라인·발광은 남기되 강도를 낮추고, 여백과 타이포그래피로 격을 올린다
- 접근성(A1~A6)은 그대로 유지한다. 랜드마크·라이브 리전·포커스 트랩·모션 축소

## 남는 위험

- **네 실제 파일을 고친다.** 승인 게이트가 있어도 승인을 습관적으로 누르면 무너진다.
  git 저장소에서 쓰는 것을 강력히 권한다 — 되돌릴 수 있어야 한다.
- **bash 실행은 네 권한 그대로다.** 네트워크·홈 디렉터리 접근을 막지 못한다.
- 화면 캡처는 Anthropic으로 전송된다.
